\begin{problem}
    En un laboratorio, a partir de un estudio bajo ciertas condiciones, se determinó que un tipo de bacteria se duplica cada 4\,\mathrm{min}.

    Si en un instante se tenía una de estas bacterias, ¿cuánto tiempo transcurrió para tener 64 de esas bacterias?

    \begin{enumerate}[label=\Alph*.]
        \item 5\,\mathrm{min}
        \item 6\,\mathrm{min}
        \item 20\,\mathrm{min}
        \item 24\,\mathrm{min}
    \end{enumerate}
\end{problem}

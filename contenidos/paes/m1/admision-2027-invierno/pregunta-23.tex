\begin{problem}
    En un laboratorio, a partir de un estudio bajo ciertas condiciones, se determinó que un tipo de bacteria se duplica cada \SI{4}{min}.

    Si en un instante se tenía una de estas bacterias, ¿cuánto tiempo transcurrió para tener \num{64} de esas bacterias?

    \begin{enumerate}[label=\Alph*.]
        \item \SI{5}{min}
        \item \SI{6}{min}
        \item \SI{20}{min}
        \item \SI{24}{min}
    \end{enumerate}
\end{problem}
